### **[[Metabolic Acidosis]]**:

| Type                                 | Mechanism                                                                         | Specific Causes                                                     | Common Triggers / Examples                                                                                   |
| ------------------------------------ | --------------------------------------------------------------------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **Anion Gap Metabolic Acidosis**     | Accumulation of organic acids increases the anion gap.                            | **Lactic Acidosis** – buildup of lactic acid.                       | Hypoxia, sepsis, severe liver disease                                                                        |
|                                      |                                                                                   | **Ketoacidosis** – buildup of ketone bodies.                        | [[Diabetic Keto Acidosis (DKA)]],  [[Substance Use Disorders]](alcohol) (alcoholic ketoacidosis), starvation |
|                                      |                                                                                   | **Renal Failure** – accumulation of uremic toxins.                  | [[Acute Kidney Failure]], [[Chronic Kidney Failure]]                                                          |
|                                      |                                                                                   | **Toxins** – ingestion of acids or substances metabolised to acids. | Methanol, ethylene glycol, salicylates                                                                       |
| **Non-Anion Gap Metabolic Acidosis** | Loss of bicarbonate or failure of renal acid excretion; anion gap remains normal. | **Gastrointestinal Bicarbonate Loss**                               | Diarrhea, pancreatic fistulas                                                                                |
|                                      |                                                                                   | **Renal Tubular Acidosis**                                          | Impaired renal acid excretion                                                                                |
|                                      |                                                                                   | **Hyperchloremic Acidosis**                                         | Excessive administration of chloride-containing IV fluids                                                    |

### **[[Respiratory Acidosis]]**:

| Type                             | Mechanism                                                                                     | Specific Causes                       | Common Triggers / Examples                                                |
| -------------------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------- | ------------------------------------------------------------------------- |
| **Acute Respiratory Acidosis**   | Rapid rise in PaCO₂ from hypoventilation; renal compensation not yet established.             | **Central Nervous System Depression** | Drug overdose (opioids, sedatives), [[Substance Use Disorders]]           |
|                                  |                                                                                               | **Acute Respiratory Conditions**      | [[Asthma 🐡]], [[Pneumonia]] [[Acute Pulmonary Oedema (APO) & ARDS 💦🫁]] |
|                                  |                                                                                               | **Neuromuscular Disorders**           | Guillain-Barré syndrome, myasthenia gravis                                |
| **Chronic Respiratory Acidosis** | Sustained elevation of PaCO₂ with gradual renal compensation; due to ongoing hypoventilation. | **[[COPD 🚬]]**                       | Long-standing hypoventilation                                             |
|                                  |                                                                                               | **Obesity Hypoventilation Syndrome**  | Reduced respiratory drive due to obesity                                  |
|                                  |                                                                                               | **Chronic Neuromuscular Disorders**   | Progressive diseases such as amyotrophic lateral sclerosis (ALS)          |
