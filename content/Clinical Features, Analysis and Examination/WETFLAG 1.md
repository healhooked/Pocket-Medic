 *Paediatric Resuscitation – WETFLAG Mnemonic*

| **Letter** | **Stands For**            | **Formula / Action**                                                                            |
| ---------- | ------------------------- | ----------------------------------------------------------------------------------------------- |
| **W**      | **Weight (kg)**           | *(Age x 3) + 7* <br>➡️ ~1–10 years                                                              |
| **E**      | **Energy (J)**            | *4 J/kg* <br>*biphasic preferred*                                                               |
| **T**      | **Tube Size (ETT)**       | *(Age ÷ 4) + 4* (uncuffed) <br>*(Age ÷ 4) + 3.5* (cuffed) <br>➡️ Use Broselow tape if available |
| **F**      | **Fluids (mL)**           | *20 mL/kg* (initial bolus of 0.9% NaCl or Hartmann’s) <br>➡️ For shock                          |
| **L**      | **Lorazepam / Line**      | *0.1 mg/kg IV lorazepam* <br>➡️ For seizures <br>**Line** = Consider IV/IO access               |
| **A**      | **Adrenaline (1:10,000)** | *10 mcg/kg = 0.1 mL/kg* IV/IO <br>➡️ For cardiac arrest (every 3–5 min)                         |
| **G**      | **Glucose**               | *2 mL/kg of 10% glucose* IV/IO <br>➡️ For hypoglycaemia                                         |

E.g. 
- **Weight**: (5 + 4) × 2 = **18 kg**
- **Energy**: 4 × 18 = **72 J**
- **Tube size**: (5 ÷ 4) + 3.5 = **4.75 mm** (cuffed ETT)
- **Fluid bolus**: 20 × 18 = **360 mL**
- **Adrenaline**: 0.1 mL/kg = **1.8 mL of 1:10,000**
- **Glucose**: 2 × 18 = **36 mL of 10% glucose**
