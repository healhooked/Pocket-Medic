| Feature               | Details                                                                                                 |
| --------------------- | ------------------------------------------------------------------------------------------------------- |
| **Cause**             | Usually **congestive heart failure (CHF)**, especially **left-sided heart failure**.                    |
| **Mechanism**         | Lying down → increased venous return → fluid overload in lungs → **pulmonary congestion** → dyspnoea.   |
| **Patient Behaviour** | Patients often **sleep with extra pillows** or **in a recliner** to avoid symptoms.                     |
| **Assessment Tool**   | You can ask: **"How many pillows do you sleep with?"** (e.g., “2-pillow orthopnoea”) to gauge severity. |
