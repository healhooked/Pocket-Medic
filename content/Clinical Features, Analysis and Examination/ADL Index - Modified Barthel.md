# ✅ Modified Barthel ADL Index

*Measure of physical disability, widely used for patients with stroke or other disabling conditions.  
Assessment can be made by anyone who knows the patient well.*

---
## 🚻 Bowels
- [ ] 0 = Incontinent or needs enemas
- [ ] 1 = Occasional accident (≤1×/wk)
- [ ] 2 = Continent
---
## 🛏 Transfer (bed to chair and back)
- [ ] 0 = Unable, no sitting balance
- [ ] 1 = Major help (1–2 people), can sit
- [ ] 2 = Minor help (verbal or physical)
- [ ] 3 = Independent
---
## 🚾 Bladder
- [ ] 0 = Incontinent or needs enemas
- [ ] 1 = Occasional accident (≤1×/wk)
- [ ] 2 = Continent
---
## 🚶 Mobility
- [ ] 0 = Immobile
- [ ] 1 = Wheelchair independent (including corners)
- [ ] 2 = Walks with help of 1 person (verbal or physical)
- [ ] 3 = Independent (may use aid)
---
## 🪒 Grooming
- [ ] 0 = Needs help with personal care
- [ ] 1 = Independent (face, hair, teeth, shaving)
---
## 👕 Dressing
- [ ] 0 = Dependent
- [ ] 1 = Needs help – can do ~½ unaided
- [ ] 2 = Independent (including buttons, zips, laces)
---
## 🚽 Toilet Use
- [ ] 0 = Dependent
- [ ] 1 = Needs some help
- [ ] 2 = Independent
---
## 🪜 Stairs
- [ ] 0 = Unable
- [ ] 1 = Needs help (verbal or physical)
- [ ] 2 = Independent
---
## 🍽 Feeding
- [ ] 0 = Unable
- [ ] 1 = Needs help (e.g., cutting food)
- [ ] 2 = Independent
---
## 🛁 Bathing
- [ ] 0 = Dependent
- [ ] 1 = Independent (bath or shower)
---
### 🧾 **Interpretation**
- Total score < 15 → usually represents **moderate disability**
- Total score < 10 → usually represents **severe disability**

*Reference: Oxford Handbook of General Practice, 3rd Edition*
