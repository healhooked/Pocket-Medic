*Autonomic Features*

| **Sign/Symptom**         | **Pathophysiological Basis**                                |
| ------------------------ | ----------------------------------------------------------- |
| *Diaphoresis (sweating)* | Sympathetic activation via adrenaline/noradrenaline release |
| *Hunger*                 | Hypothalamic response to low glucose                        |
| *Tingling (perioral)*    | Cholinergic/adrenergic activation affecting sensory nerves  |
| *Tremors*                | Beta-adrenergic stimulation of skeletal muscles             |
| *[[Tachycardia]]*        | Sympathetic drive increases heart rate                      |
| *[[Pallor]]*             | Peripheral vasoconstriction due to catecholamines           |
| *[[Palpitations]]*       | Increased cardiac contractility and HR                      |
| *Anxiety*                | Central noradrenergic surge; panic-like response            |
🧠 *Neurological Features*

| **Feature**         | **Pathophysiology**                                                  |
| ------------------- | -------------------------------------------------------------------- |
| *Altered LOC*         | Glucose is the brain’s sole fuel; depletion → impaired consciousness |
| *Lethargy*            | Mild cerebral dysfunction due to energy failure                      |
| *Behavioural changes* | Frontal lobe dysfunction from hypometabolism                         |
| *Headache*            | Cerebral vasodilation from metabolic stress                          |
| *Visual disturbances* | Occipital lobe hypoglycaemia → blurred vision, tunnel vision         |
| *Slurred speech*      | Cortical and motor pathway dysfunction                               |
| *Dizziness*           | Global cerebral underperfusion/energy failure                        |
| *Coma*                | Severe, prolonged glucose deficiency → cortical shutdown             |
