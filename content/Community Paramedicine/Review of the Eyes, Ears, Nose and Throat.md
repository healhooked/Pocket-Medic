## **General**
- **Fever / chills / weight changes** → systemic infection, inflammation, or malignancy
- **Ear** → tinnitus, vertigo, hearing loss, pain, discharge → infection, Ménière’s, trauma
- **Nose** → congestion, runny nose, nosebleeds, decreased smell → infection, allergy, polyps
- **Throat / Larynx** → pain, difficulty swallowing, hoarseness, voice changes, noisy breathing → infection, cancer, overuse, injury
- **Trachea** → noisy/difficulty breathing → obstruction
- **Neck** → lymphadenopathy, lumps, swelling → infection, malignancy
- **Face / sinuses** → pain, swelling, numbness → sinusitis, infection, nerve involvement
---
# **Eyes**
- **Contact lenses** → risk of corneal ulceration
- **Pain with eye movement** → iritis, scleritis
- **Lids stuck together in morning** → conjunctivitis
- **Eye injuries / exposure (dust, metal, welding)** → trauma, foreign body, flash burn
- **Arthritis or rashes** → systemic vasculitis affecting eyes
- **Sudden visual loss**
    - Persistent with one eye closed → visual field defect
    - Curtain over vision → amaurosis fugax
    - Previous strokes / heart issues → retinal embolus / cortical infarct
    - Eye pain → acute glaucoma, iritis
    - Trauma → optic nerve/eye injury
    - Preceding flashing lights → migraine
    - Severe ipsilateral headache → temporal arteritis
    - Weakness / tingling / bladder-bowel issues → MS / optic neuritis
    - Diabetes → diabetic retinopathy
# **Ears**
- **Hearing duration / congenital** → congenital vs acquired
- **Noise exposure (work / hobbies)** → noise-induced hearing loss
- **Ototoxic drugs (salicylates, cisplatin, gentamicin)** → drug-induced hearing loss
- **Family history** → otosclerosis
- **Recurrent ear infections** → chronic infection risk
- **Wax, trauma, meningitis history** → structural or infection-related hearing problems
- **Ringing in ears** → Ménière’s disease
# **Nose**
- **Duration / laterality** → acute infection vs septal deviation
- **Allergies / polyps / seasonality / sneezing** → allergic rhinitis
- **Injury / foreign body** → trauma, obstruction
- **Other symptoms** → loss of smell (polyps), headache/fullness (sinusitis), fever
# **Throat / Larynx / Mouth**
- **Hoarseness** → short-term = laryngitis; persistent = carcinoma, nerve injury
- **Neck injury** → trauma-related
- **Smoking** → laryngeal / lung cancer, recurrent nerve palsy
- **Steroid inhaler / voice use / recent intubation** → overuse, papilloma, injury
- **Thyroid disease** → hypothyroidism affecting voice
- **Oral pain** → toothache, TMJ, angina
- **Painful swallowing** → tonsillitis, ulcers
- **Duration** → acute = infection
- **Dental problems** → source of mouth/throat pain
