| Type of Fracture    | Common Anatomical Region          | High Yield Treatment Considerations (Prehospital)                             |
| ------------------- | --------------------------------- | ----------------------------------------------------------------------------- |
| Transverse Fracture | Femur, Tibia, Humerus             | Stabilize with splinting, assess for neurovascular status                     |
| Oblique Fracture    | Femur, Tibia, Radius              | Stabilize with splinting, monitor for shock                                   |
| Spiral Fracture     | Femur, Tibia                      | Stabilize with splinting, assess for associated injuries                      |
| Comminuted Fracture | Pelvis, Femur                     | Stabilize with pelvic binder if indicated, monitor for shock                  |
| Greenstick Fracture | Forearm (Radius and Ulna)         | Immobilize with a splint, reassure and monitor                                |
| Stress Fracture     | Metatarsals, Tibia, Femur         | Rest and immobilization, advise on activity modification                      |
| Avulsion Fracture   | Ankle (Fibula), Hip (Iliac Crest) | Stabilize with splinting, monitor for neurovascular status                    |
| Pathologic Fracture | Any bone weakened by disease      | Stabilize, assess for underlying conditions, transport for further evaluation |
